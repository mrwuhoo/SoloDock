# SoloDock v0.2 设计规范

> 由交互原型导出（2026-09-24）。原型是视觉的唯一依据；本文件供开发与 AI 编程助手逐条对照。

## 总览

### 定位与原则（已锁定）

- **定位**：一人公司（OPC）用户最好的伙伴——工作时管理精力，工作之外养成好习惯。
- **视觉**：冰蓝磨砂玻璃不改。它待在主要工作旁边，半透明、轻、退后。
- **用户**：日程多样、工作内容多样、重度使用 AI 的人；功能不为任何职业定制。
- **边界**：不承接主要工作——不生产内容、不接入或操控工作软件、不分析平台与业务数据。个人时间回顾只基于电脑活跃、专注与「在做」。
- **工作侧**：看一眼 · 记一下 · 提醒我 · 专注一会儿 · 回到刚才 · 回顾时间。**生活侧**：运动、冥想、阅读等习惯，和工作分开。

### 结构与权重

        位置内容

- 左侧页签（贴着刘海）：首页 · 待办 · 笔记 · 链接 · 剪贴 · 密钥（一级）
- 右侧页签（贴着刘海）：录制 · 时间 ｜ 生活 ｜ 设置 · 搜索 ⌘K · 通知铃铛；「重置资讯」开启后出现
- 首页卡片：今天时间线、今日随笔、今天待办、专注、AI 用量（最多 3 个订阅）、相框
- 笔记页：提示词库（第一页，原首页常用指令）｜ 笔记
- 可选（默认关闭）：快速录音卡、最近剪贴卡、当前窗口、重置资讯页签
- 删除：汽水音乐；镜子的摄像头（封面图升级为「相框」）

### 相对现状的主要变化

- 页签从「左五右四、中间空一大块」改为左右两组**贴住刘海**对称排列。
- 新增：今天时间线、刘海下沿状态、全局随手记、⌘K 搜索、通知中心、统一提醒浮窗、首次引导。
- 新增「时间」页（工作时长月历）与「生活」页（运动、冥想、阅读）；提醒新增久坐、护眼、收工时间，动效可个性化（支持者）。
- 密钥：锁定/解锁、遮蔽、机密剪贴板标记、自动锁定。剪贴板：保持现有交互，只统一视觉；后台不记录密钥与机密内容。
- 首页：快速录音与最近剪贴改为可选卡片，把位置让给「相框」；常用指令移入笔记页的「提示词库」，AI 用量加宽并支持同时显示 Claude、Codex、Grok 等。
- 待办：分类可增减、重复、自然语言日期、可读的剩余时间、「在做」。
- 设置：分组导航；开关统一主色；提醒强度与动效主题。

### 尚未确认、原型中先采用的方案

        问题原型中的处理

- 日程从哪来：先在 SoloDock 内手动添加（双平台一致）；系统日历只读接入放到之后
- 工作时长怎么算：电脑活跃（空闲少于 5 分钟）+ 专注 + 「在做」分类；不记录软件、窗口与内容
- 统一搜索：采用：面板内 ⌘K 同时搜索笔记、剪贴、待办、链接、密钥名称
- 刘海里批准 AI 操作：不做：只提醒「需要你确认」并精确跳回终端
- MCP / 本地接口给 AI 读数据：不做
- Windows：同一套设计；差异在各页「验收」中注明
- 付费：提醒浮窗的动效个性化（主题、强调色、位置、停留、文案）属于支持者权益；安全与现有功能永久免费

### 交给开发（含 GPT）的约定

- 以本原型为唯一视觉依据；每完成一页，截图与原型并排对比后再提交。
- 新建 `renderer/tokens.css` 存放全部设计变量（见「设计规范」）；组件只引用变量。
- **禁止在 styles.css 末尾追加覆盖规则**；每个组件一段样式，改组件就改那一段。
- 字号只用 11/13/14/17/22/40；圆角只用 30/22/12/8/胶囊；不允许裸色值。
- 每页「验收」清单全部满足才算完成；数据结构变更必须附迁移与回滚。

画布模拟 14 英寸 MacBook（1440×900 点），面板 1240×616 与现有代码一致。背后的文稿和终端窗口代表「主要工作」，用来检验玻璃的通透度。

## 折叠态 · 刘海状态

平时收在刘海里；有需要时，只用刘海下沿告诉你一件最要紧的事。

**状态**：空闲 / 专注中 / 录音中 / AI 需要你 / 额度不足 / 下一日程 / 稍后提醒 / 收工后 / 无刘海屏

### 视觉

- 空闲：宽 200、总高 38（刘海 32 + 下沿 6），下沿中间 14×3 药丸，颜色 `--t3`；材质沿用现有冰蓝 `rgba(226,237,250,.95)`。
- 有状态：下沿加高到 28（总高 60），**宽度仍为 200**，不向两侧扩张、不遮挡菜单栏图标。
- 内容：12px 图标 + 12/500 文字，左右内边距 12，超长省略。专注与录音在底边显示 2px 进度线。
- 「需要你确认」：外圈 1.5px 琥珀描边 + 1.8 秒扩散光环；录音：红点 1.4 秒呼吸。
- 无刘海屏：顶部居中胶囊 200×30、圆角 15、距顶 6。Windows：200×38 贴工作区顶部，避开任务栏。

### 交互

1. 悬停 150ms 后药丸加长到 28px；悬停时按空格展开面板。点击状态也可展开（悬停 + 空格为主，防止鼠标路过误触）。
2. 状态优先级，同时只显示一条：需要你确认 ＞ 录音中 ＞ 专注中 ＞ AI 额度不足（低于 20%）＞ 60 分钟内的日程 ＞ 稍后提醒 ＞ 空闲。
3. 点击有状态的下沿直接去对应位置：需要你 → 通知中心并高亮该条；录音 → 录制页；专注 → 首页专注卡；额度不足 → AI 用量详情；日程 → 首页时间线。
4. 右键下沿打开快捷菜单：暂停专注、结束录音、稍后提醒…、打开设置。

### 状态说明

- 上方按钮可切换 9 种状态。「收工后」：过了收工时间仍在使用电脑时，安静显示当前时间，不闪烁。「无刘海屏」同时代表外接显示器与 Windows 的形态。

### 验收

- [ ] 任何状态下折叠态宽度都等于 200，不超出刘海宽度。
- [ ] 状态切换高度过渡 280ms；系统开启「减弱动态效果」时无过渡、无脉冲，改为静态描边。
- [ ] 全屏应用中默认隐藏（可在设置中改）；睡眠唤醒、插拔显示器后位置正确。
- [ ] 同步修改 AGENTS.md：「折叠态不超出物理刘海」改为「空闲时不超出；有状态时只向下延伸，宽度不变」。

## 首页 · 今天

打开面板第一眼：今天有哪些时间点、要交什么、正在做什么；随笔和剪贴伸手可及。

**状态**：3 个订阅 / 2 个订阅 / 1 个订阅 / 专注中

### 视觉

- 内容区 1208×540。顶部「今天」条高 88，**不用卡片底色**，与下方卡片形成层级；卡片区 12 栅格 × 2 行，间距 12。
- 卡片占位：今日随笔 4 列 × 2 行；今天待办 3 列；专注 2 列；AI 用量 5 列（约 496 宽）；相框 3 列 × 2 行（竖幅，约 293×436）。常用指令移到笔记页的「提示词」；快速录音、最近剪贴为可选卡片，默认不显示。
- 时间线 08:00–24:00：轨道 4px；专注段 8px 主色 38%；日程为白底主色描边胶囊；截止为分类色菱形 + 上方 11px 标签；现在线主色 2px + 时间标签；AI 完成为绿色空心点。
- 卡片圆角 22、内边距 14/16；标题 13/600 `--t2`；右上角「⋯」只在悬停时出现。
- AI 用量卡按订阅数量排版：**1 个**＝左侧 40/600 大数字 + 右侧三行信息（额度重置、订阅续费、重置卡）+ 通栏进度条；**2 个**＝两栏，数字 30/600，每栏两行信息；**3 个**＝三栏，数字 24/600，每栏两行信息，栏间 1px 分隔线。
- 每个订阅显示它最紧的那个额度窗口；低于 20% 数字与进度条变琥珀色。没有可读额度的服务（如 Grok）改为显示「N 天后续费」，进度条换成灰色条纹，表示的是订阅周期而不是额度，并注明「手动」。
- 相框：照片满铺、圆角 22、1px 白色内描边；底部 42% 渐变压暗，承载说明文字（15/600 白字）与可选倒数日（12）；页码为底部小圆点。
- 已删除汽水音乐卡片与镜子摄像头；可选卡片（快速录音、最近剪贴、当前窗口）默认不显示。

### 交互

1. 今天时间线：点击左侧日期打开「时间」页；现在线每分钟更新；悬停显示详情；点击日程编辑；点击截止菱形跳到待办并高亮该条；逾期显示红色。
2. 「+ 日程」弹出小表单：标题、时间、时长、提醒；支持自然语言，如「3点 客户电话 30分钟」。
3. 「稍后提醒」：10 分钟 / 30 分钟 / 1 小时 / 自定义，加一句备注；到点走统一提醒浮窗。
4. 今日随笔：停止输入 800ms 自动保存；编辑/预览切换；每天 0 点归档为笔记「M月D日 随笔」。
5. 今天待办：显示今天到期与逾期；勾选完成可撤销；点击行跳到待办页定位；「在做」标签表示当前在做的事。
6. 专注：意图自动取「在做」的待办；点击或空格开始；结束走统一提醒；显示今日次数。
7. AI 用量：按设置中的顺序显示最多 3 个订阅；点击整张卡打开用量详情（可切换订阅）。只在卡片可见或详情打开时同步。上方可切换 1 / 2 / 3 个订阅的排版。
8. 相框：单张或相册。相册默认「每次展开面板换一张」，1.2 秒淡入，平时完全静止；悬停出现左右切换与「⋯」（固定这张、更换照片、相框设置）。可以点左右箭头试试。
9. 卡片「⋯」：尺寸（标准/宽）、隐藏、相关设置；长按 300ms 拖动排序。

### 状态说明

- 专注中：专注卡变为倒计时 + 进度条 + 暂停，刘海下沿同步显示。
- 录音不再占首页：从录制页、全局 ⌥R 或 ⌘K 开始，录音中刘海下沿显示红点。

### 验收

- [ ] 首次安装无数据：时间线显示「今天还没有安排」+「添加日程」；待办卡显示「今天没有到期的待办」；随笔显示占位提示；AI 用量卡显示「连接 Codex」。
- [ ] AI 用量卡里缺失的数据显示「—」并注明原因，不编造；已过重置时间的额度不再显示为当前额度。
- [ ] 隐藏任意卡片后，其余卡片按栅格重新填满，不出现空洞；至少保留 1 张。
- [ ] 所有文字不小于 11px；数字使用等宽数字（tabular-nums）。
- [ ] 相框照片复制到数据文件夹，长边压缩到 1600px，最多 50 张，支持 PNG/JPG/WebP/HEIC；共享屏幕或录屏时自动模糊（可关闭）。
- [ ] 没有照片时显示「放一张让你开心的照片」+「选择照片」。
- [ ] AI 用量：订阅数量变化时自动切换排版；某个订阅读取失败时，该栏显示「读取失败 · 重试」，不影响其他栏。

## 笔记 · 提示词

笔记页的第一页是「提示词库」，存放优质、常用的提示词（原首页常用指令）；第二页是随笔与所有笔记的资料库。

**状态**：提示词库（默认） / 笔记 · 预览 / 笔记 · 编辑

### 视觉

- 右侧详情：标题 22/600；元信息 12；正文最大宽 640；渲染标题、列表、任务框、引用（浅底圆角 10）、行内代码。

- 左栏顶部分段「提示词 18 / 笔记 24」切换两个库，打开笔记页默认显示提示词；提示词列表下方是分组标签（全部、精选、写作、编程、客户…，放不下时横向滚动）。
- 提示词详情：正文中的变量渲染为主色浅底标签；下方为变量表单（两列）；底部主按钮「填好后复制」。

### 交互

1. 新建（⌘N）：创建空白笔记并聚焦标题。
2. 搜索标题与正文，实时出结果，命中文字高亮。
3. 分组按更新时间；今日随笔固定在「今天」第一条。
4. 点击标题直接改名，回车确认；标题为空时取首行，或由 AI 命名（可关闭）。
5. 编辑/预览（⌘E）；预览中可以直接勾选任务框，结果写回 Markdown。
6. 「⋯」：复制 Markdown、导出 .md、删除（可撤销）。
7. 底部显示保存状态与更新时间。
8. 「提示词 / 笔记」分段切换两个库，默认提示词；记住上次停留的库；搜索框作用于当前库。
9. 分组标签筛选；「精选」只显示打了星标的优质提示词。
10. 提示词列表：标题、星标、使用次数、分组与变量数；按最近使用排序。
11. 变量：正文中用 {名称} 标记；{剪贴板} {日期} {选中文字} 自动填充。
12. 变量表单：填写后实时生成结果；上次填写的值会被记住。
13. 「填好后复制」复制最终文本并计入使用次数；「复制原文」保留变量；在 ⌘K 中也能搜索并调用。

### 状态说明

## 链接

收藏网址、按分组浏览，并能从剪贴板一键保存。

## 统一提醒浮窗

所有提醒共用一个浮窗：看得见、默认不出声、不抢焦点。番茄钟、待办到期、AI 完成与额度、久坐、护眼、收工时间、稍后提醒都走这里。

**状态**：番茄钟 · 标准 / AI 需要你 / AI 额度提醒 / 久坐提醒 / 护眼提醒 / 收工时间 / 待办到期 / 强度：安静 / 强度：醒目 / 主题：水波 / 主题：极光 / 主题：光带

### 视觉

- 浮窗宽 380，从刘海下方滑出（360ms 弹性）；玻璃圆角 20；阴影只用于这类浮层。
- 结构：34 图标（按类型着色）+ 标题 14.5/600 + 说明 12.5 + 一行操作按钮（主按钮在左）。
- 强度：安静 = 只改变刘海下沿并计数；标准 = 浮窗；醒目 = 浮窗 + 屏幕四周 90px 内发光 2.4 秒。
- 主题只影响浮窗的光效和入场：冰晶（免费，光泽扫过一次）、水波、极光、光带、晨露（支持者）。材质、布局、文字层级不变。
- 个性化（支持者）：动效主题、强调色（4 种玻璃内的色调）、出现位置（刘海下方 / 屏幕右上角）、停留时长、按提醒类型自定义文案。
- 护眼提醒使用安静样式：无按钮、20 秒环形倒计时，结束后自动消失。

### 交互

1. 刘海下沿：「安静」强度时唯一的提示（琥珀色 + 条数）；其他强度下同步变色。
2. 浮窗主体：悬停时暂停自动消失；点击空白处打开对应位置。
3. 操作按钮按类型：番茄钟 = 休息 5 分钟 / 再专注 5 分钟 / 跳过；AI 需要你 = 跳回终端 / 稍后提醒；AI 额度 = 查看用量 / 本周期不再提醒；久坐 = 开始休息 5 分钟 / 10 分钟后 / 今天不再提醒；收工 = 全部挪到明天 / 再工作 30 分钟；待办 = 完成 / 稍后 / 打开。
4. 自动消失：标准 8 秒；「需要你确认」与「待办到期」不自动消失；错过的进入通知中心。
5. 专注期间：AI 完成类只计数不弹出，专注结束后汇总为一条。
6. 提示音为可选附加，默认关闭。

### 状态说明

- 点右上角「重播动效」可重看入场。支持者主题在设置 › 提醒中可预览。

### 验收

- [ ] 浮窗不获取键盘焦点，不打断正在输入的应用；⌃⌥⏎ 触发主按钮。
- [ ] 同时多条时最多堆叠 3 张，其余合并为「还有 N 条」。
- [ ] 减弱动态效果：只淡入淡出，关闭光晕与主题动画。
- [ ] 主题为独立素材包（不在 MIT 代码中）；未解锁可预览 3 秒。
