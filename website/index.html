SoloDock

一人公司的桌面效率工作台。

让待办、笔记、专注计时与随手记录，有一个随时可达的位置。浅蓝磨砂玻璃面板，陪你把一个人的工作安排得更清楚。

当前版本 0.1.0，提供 macOS 与 Windows 安装包及 SHA-256 校验文件。主要验证平台为 macOS 13+ Apple Silicon；Windows 通过 CI 安装与重装验证，实体设备仍待补充验收。
